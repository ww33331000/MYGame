# 骑马与砍杀类手游 - 产品需求文档 (PRD)

## 1. 项目概述

### 1.1 项目名称
**《大陆风云》** (暂定名称)

### 1.2 项目类型
- 单机买断制手游
- 开放世界角色扮演游戏 (Open World RPG)
- 类骑马与砍杀 (Mount & Blade-like) 战斗系统
- 像素风格视觉表现

### 1.3 核心游戏体验
玩家可以在一个广阔的大陆上自由探索、组建商队、招募军团、单枪匹马闯荡世界、参与实时战斗、建立自己的势力，最终争霸整个大陆。

### 1.4 目标用户
- 喜欢中世纪/奇幻题材的玩家
- 偏好硬核战斗系统和自由度的玩家
- 喜爱类骑马与砍杀游戏的玩家
- 享受角色扮演和策略经营的用户

## 2. 游戏世界设定

### 2.1 世界规模

| 元素 | 数量 | 说明 |
|------|------|------|
| 城镇 | ~40个 | 大型定居点， 经济中心 |
| 城堡 | ~120个 | 中型防御据点 |
| 村庄 | ~300个 | 小型农业定居点 |
| 道路 | 若干 | 连接各定居点的交通网络 |

### 2.2 地理与环境
- **地形类型**: 平原、森林、山脉、沙漠、沼泽、沿海
- **气候系统**: 不同地区有不同气候，影响旅行和战斗
- **季节变化**: 春夏秋冬四季，影响物价和NPC行为

### 2.3 势力划分
- **初始势力**: 6-8个不同文化和特色的王国/势力
- **势力关系**: 敌对、联盟、中立、战争状态
- **势力领土**: 城镇、城堡、村庄有隶属关系

### 2.4 城镇/城堡/村庄关系
```
势力
  ├── 城镇 (每个城镇拥有周边3-5个村庄)
  │     ├── 村庄 A
  │     ├── 村庄 B
  │     └── 村庄 C
  └── 城堡 (每个城堡控制周边2-4个村庄)
        ├── 村庄 D
        └── 村庄 E
```

## 3. 核心游戏系统

### 3.1 大地图系统 (World Map)

#### 3.1.1 功能描述
- 展示整个游戏世界
- 显示所有城镇、城堡、村庄位置
- 显示道路网络和地形
- 支持缩放和平移

#### 3.1.2 玩家交互
- 点击目标位置开始旅行
- 显示当前位置和目的地距离
- 显示途中的随机事件触发点
- 显示敌对势力范围

#### 3.1.3 旅行系统
- **旅行速度**: 根据地形、天气、载具变化
- **旅行时间**: 模拟时间流逝
- **随机遭遇**: 强盗、商队、流浪者、野生动物
- **商队保护**: 玩家可以组建商队进行贸易

### 3.2 战斗系统 (Battle System)

#### 3.2.1 战斗类型
1. **野战**: 大地图上的随机遭遇
2. **攻城战**: 攻击城镇或城堡
3. **守城战**: 防御敌军攻击
4. **单挑**: 与敌方首领一对一决斗

#### 3.2.2 战斗机制
- **实时战斗**: 3D俯视角/等距视角
- **攻击方向**: 上、下、左、右四个方向
- **攻击类型**: 轻攻击、重攻击、格挡、闪避
- **武器系统**: 近战(剑、斧、矛)、远程(弓、弩)
- **骑乘战斗**: 骑马作战，冲击力判定

#### 3.2.3 军团战斗
- 玩家可以指挥多个单位
- 编队系统: 编组、阵型指令
- 士气系统: 影响军队战斗力
- 疲劳度: 影响士兵战斗效率

### 3.3 角色扮演系统 (RPG System)

#### 3.3.1 角色属性
| 属性 | 说明 |
|------|------|
| 力量 (STR) | 影响近战伤害、负重量 |
| 敏捷 (AGI) | 影响攻击速度、闪避率 |
| 体质 (VIT) | 影响生命值上限、耐力 |
| 智力 (INT) | 影响经验获取、技能解锁 |
| 魅力 (CHA) | 影响NPC好感度、议价能力 |

#### 3.3.2 技能系统
- **战斗技能**: 剑术、斧术、枪术、弓术、骑术
- **生活技能**: 交易、说服、领导、锻造、狩猎
- **特殊技能**: 需要特定条件解锁

#### 3.3.3 等级系统
- 战斗获得经验值
- 升级后获得属性点和技能点
- 等级上限: 50级

### 3.4 装备系统 (Equipment System)

#### 3.4.1 装备类型
| 部位 | 可装备物品 |
|------|------------|
| 头部 | 头盔、头巾、皇冠 |
| 身体 | 铠甲、皮甲、袍子 |
| 双手 | 剑、斧、矛、法杖 |
| 副手 | 盾牌、弓、弩 |
| 脚部 | 靴子、护胫 |
| 坐骑 | 马、骆驼、战象 |

#### 3.4.2 装备属性
- **品质等级**: 普通、优秀、精良、史诗、传说
- **基础属性**: 防御、攻击、速度
- **附加属性**: 生命恢复、耐力恢复、抗性等
- **套装效果**: 集齐套装获得额外加成

#### 3.4.3 装备获取
- 商店购买
- 战斗掉落
- 任务奖励
- 锻造打造
- 探索发现

#### 3.4.4 锻造系统
- 收集材料
- 学习配方
- 打造武器和防具
- 强化和升级装备

### 3.5 商队系统 (Caravan System)

#### 3.5.1 商队功能
- 在不同城镇间进行贸易
- 赚取金币的主要方式之一
- 可携带大量货物
- 需要护卫保护

#### 3.5.2 商队管理
- 组建商队: 选择护卫和驮马
- 规划路线: 选择旅行路径
- 风险管理: 遇到强盗的可能性
- 收益计算: 根据距离和货物价值

#### 3.5.3 贸易系统
- 各城镇物价差异
- 根据供需关系波动
- 特殊事件影响物价
- 议价技能影响成交价格

### 3.6 军团系统 (Army System)

#### 3.6.1 军团招募
- 在城镇、城堡招募士兵
- 不同势力有不同兵种
- 兵种之间有相克关系
- 高级兵种需要特定条件

#### 3.6.2 兵种分类
| 等级 | 近战 | 远程 | 骑兵 |
|------|------|------|------|
| 初级 | 民兵、步兵 | 弓兵 | 骑乘民兵 |
| 中级 | 剑士、斧兵 | 弩兵 | 轻骑兵 |
| 高级 | 武士、骑士 | 精锐弓兵 | 重骑兵 |
| 精英 | 精英战士 | 神射手 | 圣殿骑士 |

#### 3.6.3 军团指挥
- 编队控制
- 阵型选择: 楔形、方形、雁形
- 战术指令: 进攻、防御、包围、撤退
- 军团士气维护

### 3.7 势力系统 (Faction System)

#### 3.7.1 势力特性
- 每个势力有独特文化和兵种
- 势力关系动态变化
- 领土扩张和收缩
- 势力兴衰史

#### 3.7.2 建立势力
- 占领城堡或城镇
- 任命官员管理
- 征收赋税
- 组建专属军团

#### 3.7.3 争霸大陆
- 发起战争
- 占领敌方领土
- 消灭敌方势力
- 最终统一大陆

### 3.8 任务系统 (Quest System)

#### 3.8.1 主线任务
- 统一大陆的必经之路
- 与势力剧情相关
- 引导玩家了解世界

#### 3.8.2 支线任务 (随机生成)
| 任务类型 | 触发条件 | 奖励 |
|----------|----------|------|
| 护送任务 | 城镇公告板 | 金币、经验 |
| 剿匪任务 | 击败强盗营地 | 装备、声誉 |
| 贸易任务 | 商人在路上 | 金币、物品 |
| 调查任务 | 酒馆打听 | 情报、线索 |
| 竞技大赛 | 城镇竞技场 | 荣誉、装备 |

#### 3.8.3 任务生成算法
- 基于地点、势力关系、玩家等级
- 随机组合任务要素
- 确保任务难度与玩家匹配
- 任务链和任务分支

## 4. 游戏界面设计

### 4.1 主界面布局
```
┌─────────────────────────────────────────┐
│  菜单栏 (设置、背包、角色、地图)          │
├─────────────────────────────────────────┤
│                                         │
│              游戏主视图                   │
│        (大地图/战斗/场景对话)             │
│                                         │
├─────────────────────────────────────────┤
│  状态栏 (金币、人口、日期、天气)           │
└─────────────────────────────────────────┘
```

### 4.2 像素风格规范
- **分辨率**: 基础 16x16 像素单元
- **角色尺寸**: 32x32 或 64x64
- **建筑尺寸**: 根据级别 32x32 到 128x128
- **配色方案**: 复古但不浑浊，清晰辨识
- **动画帧率**: 8-12 FPS 像素动画

### 4.3 UI色调规划
- **主色调**: 深褐色 (#4a3728) - 中世纪质感
- **辅助色**: 暖金色 (#c9a227) - 高亮和重要信息
- **背景色**: 羊皮纸色 (#f4e4bc) - 对话框和面板
- **危险色**: 暗红色 (#8b0000) - 敌对和警告
- **安全色**: 森林绿 (#228b22) - 友好和中立

## 6. 游戏流程

### 6.1 开局流程
1. 创建角色 (姓名、头像、难度)
2. 选择出生势力/地区
3. 新手教程任务
4. 获得初始装备和金500币
5. 自由探索开始

### 6.2 中期玩法 (10-30小时)
- 组建商队进行贸易
- 招募军团参与战斗
- 完成各种支线任务
- 加入某一势力
- 开始建立自己影响力

### 6.3 后期玩法 (30+小时)
- 建立自己的势力
- 发动统一战争
- 占领所有城镇和城堡
- 消灭所有敌对势力
- 达成全大陆统一

## 7. 技术需求

### 7.1 平台要求
- **目标平台**: Web浏览器 (HTML5 Canvas)
- **最低配置**: 现代浏览器，无特殊硬件要求
- **推荐配置**: Chrome 90+, Firefox 88+, Safari 14+

### 7.2 性能指标
- **帧率**: 60 FPS 战斗流畅度
- **加载时间**: 首屏 < 3秒
- **内存占用**: < 512MB
- **存储**: 本地存储存档 < 10MB

### 7.3 数据持久化
- 浏览器 LocalStorage 存储
- 自动存档机制
- 最多保存3个存档位

## 8. 开发里程碑

### Phase 1: 核心引擎 (2-3周)
- 游戏框架搭建
- 大地图系统
- 基础战斗系统
- 角色移动和控制

### Phase 2: 世界系统 (2-3周)
- 世界生成算法
- 城镇/城堡/村庄系统
- 势力关系系统
- 基础UI界面

### Phase 3: 角色成长 (2-3周)
- 属性和技能系统
- 装备系统
- 锻造系统
- 商店系统

### Phase 4: 战斗深化 (2-3周)
- 军团战斗系统
- 攻城/守城战
- AI战斗逻辑
- 战斗UI优化

### Phase 5: 玩法扩展 (2-3周)
- 商队系统
- 任务系统
- 随机事件

- 新手教程
- 平衡性调整

## 9. 风险与挑战

### 9.1 技术风险
- **性能优化**: 大规模战斗渲染
- **AI路径finding**: 复杂地形导航
- **存档系统**: 浏览器存储限制

### 9.2 设计风险
- **内容深度**: 防止后期内容枯竭
- **上手难度**: 新手引导设计
- **重复可玩性**: 随机性和多样性

### 9.3 应对策略
- 使用增量加载和LOD技术
- 设计多层次的新手引导
- 引入程序化生成和随机事件
