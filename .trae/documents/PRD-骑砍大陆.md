# 骑砍大陆 - 产品需求文档

## 1. 产品概述

### 项目概述
《骑砍大陆》是一款类骑马与砍杀风格的像素风格开放世界手游，采用单机买断制。玩家可以在一个广袤的大陆上自由探索，组建商队、招募军团、单枪匹马闯荡世界，体验势力争霸的史诗旅程。

### 核心目标
- 打造一款深度还原骑马与砍杀核心玩法的像素风格手游
- 提供自由度高、内容丰富的开放世界体验
- 支持离线单机游玩，一次购买永久畅玩

### 目标用户
- 喜欢骑马与砍杀系列的玩家
- 偏好硬核战斗和策略的玩家
- 享受开放世界探索的玩家

## 2. 世界设定

### 地图规模
| 地点类型 | 数量 | 说明 |
|---------|------|------|
| 城镇 | 40座 | 主要城市，设有市场、兵营、酒馆 |
| 城堡 | 120座 | 军事据点，有战略价值 |
| 村庄 | 300个 | 资源产地，隶属城镇/城堡 |
| 道路 | 若干 | 连接各据点的交通网络 |

### 势力划分
- 6个主要势力，每个势力拥有不同特色兵种
- 势力之间可结盟、宣战、进行领土争夺
- 城池陷落会被征服，附属村庄也会易主

### 隶属关系
```
势力 → 城镇 → 村庄/城堡
       城堡 → 村庄
```

## 3. 核心功能模块

### 3.1 世界地图系统
- **大地图浏览**: 缩放查看整个大陆，点点表示城镇/城堡/村庄
- **快速旅行**: 点击目的地进行移动，显示预计时间
- **随机事件**: 旅行中可能遭遇强盗、商队、散兵等
- **地形系统**: 平原、森林、山地、河流、沙漠等

### 3.2 角色系统
- **角色创建**: 选择性别、面部特征、起始背景
- **属性系统**:
  - 力量: 影响近战伤害、负重量
  - 敏捷: 影响攻击速度、闪避率
  - 智力: 影响物品制作、交易利润
  - 魅力: 影响招募效率、NPC好感度
- **技能系统**:
  - 双手武器/单手武器/长柄武器/弓弩/投掷
  - 骑术/侦察/向导/战术/教练
  - 交易/说服/威压/交易税

### 3.3 装备系统
- **装备部位**: 头部、躯干、手臂、腿部、武器、盾牌、坐骑
- **装备品质**: 普通 → 优秀 → 精良 → 史诗 → 传说
- **装备属性**: 攻击力、防御力、速度加成、特效
- **打造系统**:
  - 收集材料（矿石、皮料、布料、金属锭）
  - 铁匠铺打造装备
  - 提升打造技能可制作更高级装备
- **升级系统**: 使用材料强化装备属性

### 3.4 战斗系统
- **大地图战斗**: 队伍遭遇后进入战术视图
  - 指挥队伍冲锋、防守、包围
  - 使用技能（激励、溃败敌军、坚守）
- **战场战斗**: 实时战斗视图
  - WASD移动，鼠标攻击
  - 轻重攻击、格挡、闪避
  - 骑砍特有操作：马上战斗、枪刺、弓射
- **攻守城战**:
  - 攻方：云梯、攻城锤、围城
  - 守方：滚木、热油、弓弩

### 3.5 商队系统
- **商队组建**: 雇佣护卫、购买货物
- **贸易路线**: 低买高卖赚取利润
- **风险收益**: 商队可能遭遇劫匪
- ** caravan 技能**: 影响护卫效率、议价能力

### 3.6 军团系统
- **军团创建**: 需拥有城堡作为基地
- **兵种招募**: 城镇/城堡兵营招募
- **军团规模**: 最高100人
- **军团升级**: 提升等级解锁高级兵种
- **自动巡逻**: 设置后自动巡逻领地

### 3.7 势力系统
- **创建势力**: 至少占领1座城镇后可宣布独立
- **领土管理**: 任命领主、收取税收
- **外交系统**: 宣战、议和、结盟、贸易协定
- **争霸目标**: 统一全大陆

### 3.8 任务系统
- **主线任务**: 引导玩家熟悉游戏，建立势力
- **支线任务**:
  - 随机生成的委托（护送、讨伐、采集）
  - 城镇/城堡NPC的个人任务
  - 商会任务、领主任务
- **任务难度**: 简单/普通/困难/传说

## 4. 界面设计

### 4.1 主界面布局
```
┌─────────────────────────────────────┐
│  角色状态栏  │  金币/日期  │ 菜单  │
├─────────────────────────────────────┤
│                                     │
│           世界地图/战斗视图           │
│                                     │
├─────────────────────────────────────┤
│  队伍 │ 装备 │ 技能 │ 任务 │ 势力   │
└─────────────────────────────────────┘
```

### 4.2 视觉风格
- **像素风格**: 16x16基础分辨率，放大显示
- **色彩方案**:
  - 主色: 深棕色(#4a3728)代表中世纪氛围
  - 辅助色: 暖金色(#c9a227)用于高亮
  - 战斗用红色(#8b0000)和蓝色(#1e3a5f)区分敌我
- **字体**: 像素风格等宽字体
- **UI风格**: 木质边框、羊皮纸背景

### 4.3 响应式设计
- 优先适配桌面端（1920x1080）
- 平板适配（1024x768）
- 手机适配（768x1024竖屏）

## 5. 游戏流程

### 5.1 开局流程
```
创建角色 → 选择出生地 → 新手教程 →
自由探索 → 主线任务开启
```

### 5.2 中期流程
```
积累资本 → 组建商队 → 贸易获利 →
招募军团 → 攻占城堡 → 建立势力
```

### 5.3 后期流程
```
势力发展 → 领土扩张 → 外交博弈 →
统一大陆 → 结局动画
```

## 6. 技术实现

### 6.1 渲染方案
- Canvas 2D渲染器
- 分层渲染：地形层、对象层、UI层、战斗层

### 6.2 数据持久化
- LocalStorage存储存档
- 自动存档/手动存档

### 6.3 性能优化
- 视口裁剪，只渲染可见区域
- 对象池复用
- 批量绘制减少draw call

## 7. 音效与音乐

### 音效
- 战斗音效：刀剑碰撞、弓箭呼啸、马蹄声
- UI音效：按钮点击、道具获得、升级
- 环境音：城镇喧嚣、森林鸟鸣、战场喊杀

### 音乐
- 背景音乐：城镇曲、野外曲、战斗曲、胜利曲
- 风格：中世纪/奇幻风格8-bit音乐
