# 骑砍大陆 - 技术架构文档

## 1. 架构设计

```
┌─────────────────────────────────────────────────────┐
│                    游戏主循环                         │
├─────────────────────────────────────────────────────┤
│  渲染层  │  逻辑层  │  数据层  │  输入层             │
├─────────────────────────────────────────────────────┤
│ Canvas2D │ GameState │ DataManager │ InputHandler   │
│ Camera   │ WorldMap  │ SaveManager │ TouchControl   │
│ Sprite   │ Battle   │ AudioManager│ Keyboard       │
└─────────────────────────────────────────────────────┘
```

## 2. 技术选型

### 核心框架
- **原生JavaScript**: 无外部依赖，确保加载速度
- **HTML5 Canvas**: 2D渲染
- **Webpack**: 模块打包

### 第三方库
- **howler.js**: 音频播放
- **localforage**: 大量数据存储

## 4. 核心类设计

### 4.1 Game（游戏主类）
```javascript
class Game {
  - canvas: HTMLCanvasElement
  - ctx: CanvasRenderingContext2D
  - state: 'menu' | 'world' | 'battle' | 'inventory'
  - player: Player
  - world: WorldMap
  - party: Party
  - ui: UIManager
  + init()
  + update(deltaTime)
  + render()
  + changeState(newState)
}
```

### 4.2 WorldMap（世界地图）
```javascript
class WorldMap {
  - locations: Location[]
  - factions: Faction[]
  - paths: Path[]
  - gridSize: number
  + getLocationAt(x, y): Location
  + getLocationsByType(type): Location[]
  + getPathBetween(from, to): Path
  + updateFactions()
}
```

### 4.3 Location（地点）
```javascript
class Location {
  - id: string
  - name: string
  - type: 'town' | 'castle' | 'village'
  - position: {x, y}
  - faction: Faction
  - owner: Faction
  - buildings: Building[]
  - troops: Troop[]
  + getTroops(): Troop[]
  + recruit(troopType): boolean
  + fortify()
}
```

### 4.4 Player（玩家）
```javascript
class Player {
  - name: string
  - level: number
  - exp: number
  - attributes: { strength, agility, intelligence, charisma }
  - skills: Map<Skill, level>
  - equipment: Equipment[]
  - gold: number
  - inventory: Item[]
  + levelUp()
  + addSkillExp(skill, amount)
  + equip(item)
  + unequip(slot)
}
```

### 4.5 Party（队伍）
```javascript
class Party {
  - name: string
  - leader: Player
  - troops: Troop[]
  - position: {x, y}
  - targetPosition: {x, y}
  - speed: number
  - maxSize: number
  + addTroop(troop)
  + removeTroop(troop)
  + moveTo(x, y)
  + getTotalStrength(): number
}
```

### 4.6 BattleManager（战斗管理）
```javascript
class BattleManager {
  - phase: 'tactical' | 'realTime'
  - playerParty: Party
  - enemyParty: Party
  - battlefield: Battlefield
  - combatUnits: CombatUnit[]
  + startTacticalPhase()
  + startRealTimePhase()
  + issueOrder(order)
  + checkVictory(): 'player' | 'enemy' | null
  + endBattle()
}
```

## 5. 数据模型

### 5.1 存档数据结构
```javascript
{
  version: "1.0.0",
  timestamp: Date,
  player: {
    name: string,
    level: number,
    exp: number,
    attributes: { str, agi, int, cha },
    skills: { [skillName]: level },
    equipment: { [slot]: itemId },
    gold: number,
    inventory: [itemId, ...]
  },
  party: {
    troops: [{ type, count }, ...],
    position: { x, y }
  },
  world: {
    locations: [{ id, ownerId, troops }, ...],
    factions: [{ id, relations }, ...]
  },
  quests: {
    active: [questId, ...],
    completed: [questId, ...]
  }
}
```

## 6. 渲染架构

### 6.1 分层渲染
1. **地形层**: 草地、河流、道路
2. **装饰层**: 树木、石头、建筑图标
3. **对象层**: 单位、商队、玩家
4. **特效层**: 攻击特效、尘土
5. **UI层**: 血条、名字标签
6. **界面层**: 菜单、对话框

### 6.2 视口系统
```javascript
class Camera {
  - x: number
  - y: number
  - zoom: number
  - viewportWidth: number
  - viewportHeight: number
  + follow(target)
  + pan(dx, dy)
  + zoomTo(level)
  + worldToScreen(wx, wy): {x, y}
  + screenToWorld(sx, sy): {x, y}
}
```

## 7. 战斗流程

### 7.1 战术阶段
1. 双方队伍在战场部署
2. 玩家选择战术：冲锋/包围/坚守/撤退
3. AI自动决策

### 7.2 实时阶段
1. 玩家控制主角单位
2. 队伍AI自动战斗
3. 击溃敌军或撤退

## 8. 随机任务生成

### 8.1 任务模板
```javascript
{
  "type": "escort" | "bandit" | "deliver" | "gather",
  "title": "护送商队",
  "description": "护送{from}到{to}",
  "objectives": [...],
  "rewards": { gold, exp, reputation },
  "difficulty": 1-5
}
```

### 8.2 生成规则
- 根据玩家等级调整难度
- 根据当前位置选择就近目标
- 随机遭遇决定任务类型
