# 中世纪战争 - Web 版 Demo

这是一个基于 Three.js 的 3D 中世纪战争游戏 Demo，无需安装任何软件，直接在浏览器中打开即可运行。

## 快速开始

### 方法 1：直接打开（最简单）
1. 双击 `index.html` 文件
2. 使用 Chrome / Edge / Firefox 等现代浏览器打开
3. 点击「开始游戏」即可游玩

### 方法 2：本地服务器（推荐，性能更好）
如果直接打开遇到问题，可以启动一个本地服务器：

```bash
# 方法 A：Python 3
cd MedievalWarfare_WebDemo
python3 -m http.server 8080
# 然后在浏览器访问 http://localhost:8080

# 方法 B：Node.js
npx serve MedievalWarfare_WebDemo
```

## 游戏玩法

### 主菜单
- 点击「开始游戏」进入大地图
- 点击「操作说明」查看控制方式

### 大地图
- 地图上有 6 个节点（村庄、森林、城堡等）
- 点击节点查看详情
- 只能前往与当前位置相连的节点
- 红色城堡节点有敌人驻守
- 到达有敌人的节点后，点击「发起进攻」进入战斗

### 战斗场景
- 点击游戏画面锁定鼠标
- WASD / 方向键移动
- 鼠标移动控制视角
- 鼠标左键 攻击（挥剑）
- 鼠标右键 防御（减少 70% 伤害）
- Shift 奔跑
- Esc 解锁鼠标/暂停

### 胜利条件
- 击败场景中的所有敌人即可获胜
- 生命值归零则战败

## 游戏特色

- 🎮 完整的大地图 + 战斗双模式
- ⚔️ 真实的 3D 战斗系统（攻击、防御、伤害计算）
- 🤖 敌人 AI（巡逻、追击、攻击）
- 🏰 6 个可探索的地图节点
- ❤️ 实时血条显示
- 🌲 沉浸式 3D 环境（树木、岩石、光影）

## 系统要求

- 现代浏览器（Chrome 90+ / Edge 90+ / Firefox 88+）
- 支持 WebGL 的显卡
- 建议使用鼠标获得最佳体验

## 故障排除

### 画面黑屏 / 无法加载
- 确保使用现代浏览器
- 尝试用本地服务器方式打开
- 按 F12 打开控制台查看错误

### 鼠标无法控制视角
- 点击游戏画面以锁定鼠标
- 确保页面已获得焦点

### 游戏卡顿
- 关闭其他占用资源的标签页
- 降低浏览器窗口大小
- 使用 Chrome 浏览器效果最佳
