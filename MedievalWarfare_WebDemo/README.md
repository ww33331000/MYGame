# 中世纪战争 - 全3D Web版 Demo

基于 Three.js 的完整 3D 中世纪战争游戏，**浏览器直接打开即可运行**，无需安装任何软件。

## ⚡ 快速开始

### 最简单方式
直接用 Chrome / Edge / Firefox 浏览器打开 `index.html`

### 本地服务器方式（推荐）
如果直接打开有问题，启动一个本地服务器：

```bash
# Python 3
cd MedievalWarfare_WebDemo
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 🎮 游戏玩法

### 主菜单
- **开始游戏**：进入 3D 大地图
- **操作说明**：查看控制方式

### 3D 大地图
- 在开放的 3D 世界中自由探索
- 找到带有红色标记的敌人据点
- 接近据点时，按 **E 键**进入战斗

地图上的地点：
- 🏠 **起始村庄**（绿色标记，安全区）
- 🌲 **黑暗森林**（森林营地，2个敌人）
- 🏰 **边境哨站**（城堡，3个敌人）
- 🏛️ **古老遗迹**（遗迹，3个敌人）
- ⛺ **强盗营地**（营地，4个敌人）
- 👑 **领主城堡**（最终城堡，5个敌人）

### 战斗场景
- **WASD / 方向键** - 移动
- **鼠标移动** - 视角（点击画面锁定鼠标）
- **鼠标左键** - 挥剑攻击
- **鼠标右键（按住）** - 举盾防御（减少70%伤害）
- **Shift** - 奔跑
- **空格** - 跳跃
- **Esc** - 解锁鼠标

### 目标
击败所有敌人据点，最终征服领主城堡！

## 🖥️ 系统要求

- 现代浏览器（Chrome 90+ / Edge 90+ / Firefox 88+ / Safari 14+）
- 支持 WebGL 的显卡
- 建议使用鼠标获得最佳体验
- 推荐屏幕分辨率：1280x720 以上

## 🔧 技术说明

- 引擎：Three.js r128
- 渲染：WebGL + 阴影贴图
- 控制：Pointer Lock API + 第三人称相机
- 所有素材为程序化生成的几何体
- 单文件 HTML，约 50KB

## ❓ 常见问题

### Q: 画面黑屏？
A: 请确保使用现代浏览器，并检查浏览器控制台（F12）是否有错误。也可以尝试用本地服务器方式运行。

### Q: 鼠标不能控制视角？
A: 点击游戏画面以锁定鼠标。按 Esc 可以解锁。

### Q: 游戏很卡？
A: 关闭其他占用资源的程序，或减小浏览器窗口。Chrome 浏览器性能最佳。

### Q: 找不到敌人？
A: 向地图边缘探索，红色发光标记就是敌人据点。接近后按 E 进入战斗。

### Q: 怎么返回大地图？
A: 战斗胜利或失败后，点击「返回大地图」按钮。
